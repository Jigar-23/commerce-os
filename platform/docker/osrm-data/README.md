# CommerceOS Pinned OSRM Routing Data

This directory hosts the pinned OSRM road-network dataset (`routing.osrm` and associated MLD partition and cell structures).
The dataset is initialized and maintained via `platform/docker/osrm-entrypoint.sh` and pre-built into `platform/docker/Dockerfile.osrm`.
Coordinates covered include the primary operational zones in Rewari (28.201, 76.614) and Gurugram (28.4595, 77.0266).
